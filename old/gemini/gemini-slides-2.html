Parametric vs. Grounded Knowledge

Parametric Knowledge

Knowledge compressed into weights during training. General syntax, public patterns, and framework basics. Fixed at the model's training cutoff.

Grounded Context

Repository-level truth. Private APIs, custom conventions, and current file state. Provided via AGENTS.md + Instructions.

The Decision Gap: Vercel found agents skip framework docs 44% of the time because they think they already know the answer via parametric memory.

[02:00 - 05:00] THE CORE PROBLEM
"Parametric knowledge is stale and generic. Your private APIs, your naming conventions, your monorepo structure — none of that is in the training data. When agents can't find grounded context, they guess. And they guess confidently."

The Silent Killer: Context Rot

🟢 0–50%: Safe Zone (Instructions Retained)
🟡 50–80%: Compression Zone (Summarization)
🔴 80–95%: Danger Zone (Rules Discarded)
💀 95%+: Context Rot (Conventions Lost)

Even with 1M+ token windows, auto-compaction silently discards your architectural rules.

[05:00 - 07:00] WINDOW DECAY
"As the window fills, agents silently auto-compact. Your project conventions — the first things discarded. The code compiles, but it violates your architecture. This is why we need structured context."

Two Models of Context Delivery

Passive Steering (Push)

  • System Prompt Injection
  • Always Present Context
  • AGENTS.md + Instructions

Active Retrieval (Pull)

  • On-demand Search (RAG)
  • Agent Initiates Retrieval
  • Devin Search / Grep / Read

Passive wins reliability. Active wins scale.

[07:00 - 10:00] PUSH VS PULL
"There are exactly two ways to get context to an agent. Passive — you push it. Active — the agent pulls it. The key insight: passive eliminates the Decision Gap. The agent can't skip what's already in its prompt."

Five Pillars of AI-Native

1. Unified Knowledge

One root AGENTS.md + global copilot-instructions.md.

2. Scoped Precision

Glob-matched *.instructions.md files. React rules only load for .tsx.

3. Monorepo Mastery

Nearest-file precedence. Local AGENTS.md overrides root.

[12:00 - 14:00] REPO STRUCTURE
"Unified Knowledge at root. Scoped Precision using glob patterns. Monorepo Mastery via nearest-file precedence. This prevents the agent from applying backend rules to frontend files."

Maintenance & Docs

4. AI-Readable Docs

Structured headings + llms.txt. Optimize for machine-discoverability over aesthetics.

5. Living Maintenance

Validation scripts + Quarterly audits. Treat context as production code; break CI on stale docs.

[14:00 - 15:00] PILLARS 4-5
"AI-Readable Docs via llms.txt. Living Maintenance via validation scripts. Treat context as code — this tree is what your repo should look like when you're done."

Anthropic: Progressive Disclosure

  • Level 1: YAML Frontmatter

  • Level 2: SKILL.md Body
    Loaded ON MATCH. Workflow & instructions.
  • Level 3: Linked Resources
    Loaded ON NEED. Heavy guides & reference scripts.
[15:00 - 17:00] SCALE ARCHITECTURE

Monorepo: Nearest-File Routing

Route Precedence

Agent editing frontend/Button.tsx loads:
1. frontend/AGENTS.md (Override)
2. /Root/AGENTS.md (Fallback)

No Leakage: Frontend agents never load backend rules.

[22:00 - 23:00] SCALE LOGIC
"Nearest-file precedence prevents context leakage. This is how you prevent applying Express conventions to React components."
